# Fit objects tool

Use the **Fit objects** tool to align an imported image or object with background mapping or another imported object.

1. Place the object you plan to overlay to the side of the mapping area or reference object
2. Right-click the object and select **Transform** > **Fit objects**
3. Draw a line between two recognizable points on the object
4. Draw a matching line between the same two points on the background mapping or reference object. Use the live preview to check the alignment and adjust its opacity using the slider in the top-left dialog
5. Press **Enter** to finish

If you need to undo a point while fitting, right-click and try again.
