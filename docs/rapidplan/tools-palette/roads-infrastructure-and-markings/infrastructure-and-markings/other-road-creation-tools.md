# Other road creation tools

Often, the **Road** tool alone is all you need to create a roadway. RapidPlan provides additional road tools in the Roads tab of the **Tools palette**.

## Turn Lane tool

This tool is used for making a slip lane or a turning lane.

To create a turning lane:

1. Select the **Turn Lane** tool from the Roads tab in the **Tools palette**.
2. Select the road where you want the turning lane to start.
3. Select the middle of the turning lane to place a **control point**.
4. Select where you want the turning lane to end.
5. Right-click to drop the tool.

    ![Turning_Lane_on_left_and_a_Slip_Lane_on_right_using_the_Turn_Lane_tool](./assets/Turning_Lane_on_left_and_a_Slip_Lane_on_right_using_the_Turn_Lane_tool.png)

## Arc Road tool

This tool allows you to create a precise arc in a road with ease. As you can see in the images below, it is created from a radius.

To create a road arc:

1. Select the **Arc Road** tool in the Roads tab of the **Tools palette**.
2. Select the canvas to set the radius of the road arc.
3. Select the canvas again to start drawing the road arc.
4. Drag in the direction you want the road to follow.
5. Select the canvas to place the road.
6. Right-click to drop the tool.

    ![Arc_Road](./assets/Arc_Road.png)

You can also choose to set the arc's radius, angle and direction manually in the **Arc** tab of the **Properties palette**.

![Arc_Road_Properties](./assets/Arc_Road_Properties.png)

## Roundabout tool

The **Roundabout** tool creates a roundabout that connects to other roads.

To create a roundabout:

1. Select the **Roundabout** tool in the Roads tab of the **Tools palette**.
2. Select the canvas to place the center of the roundabout.
3. Move the pointer to adjust the roundabout size.
4. Right-click to finish.

    ![Roundabout](./assets/Roundabout.png)

## Road Corner tool

This tool allows you to easily create road corners for your roads. It is controlled by three **control points** to assist in the shape and positioning of the object and a single shape point that controls the shape of the curve.

To create a road corner:

1. Select the **Road Corner** tool from the Roads tab in the **Tools palette**.
2. Select where you want the corner to begin.
3. Select the inner corner of the object.
4. Select the final corner.
5. Select again to position the shape point.

The completed object has three **control points** and one shape point for adjusting its position and curve.

![The_Road_Corner_Tool](./assets/The_Road_Corner_Tool.png)

## Road Region tool

The **Road Region** tool is a free-form road tool for drawing irregular paved surfaces such as parking lots.

**To create a road region:**

- Select the **Road Region** tool from the Roads tab in the **Tools palette**.
- Start your region at the smallest corner and click once to start drawing.
- Move in either a clockwise, or anti-clockwise order, clicking at each of your region's corner points (**Note:** Remember, you can hold **Shift** to keep the corners of your region perfectly straight).
- When you have placed your last point, right-click to stop drawing, then right-click again to drop the **Road Region** tool.

![Road_Region_Tool](./assets/Road_Region_Tool.png)
